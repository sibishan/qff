Never opened a notebook?

Three ways
to open them.

Google Colab

Easiest, nothing to install. Hit Open in Colab, sign in with a Google account, and run cells with Shift + Enter. It's what we'll use on the day.

VS Code

Download the .ipynb, open it in VS Code with the Python and Jupyter extensions installed, then pick a Python 3.10+ kernel.

JupyterLab

Got Python locally? Run pip install jupyterlab, then jupyter lab in the folder you saved the notebook to.

Stuck on setup? That's what we're here for. Ask in the Discord before the day, or grab an organiser at check in.
